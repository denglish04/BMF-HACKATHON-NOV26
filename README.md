### Add your project

1. Put your project in your own GitHub repo and turn on GitHub Pages
   (your repo → **Settings → Pages → Build and deployment → Deploy from a branch**, pick `main` and `/ (root)` or `/docs`).
   Your site will be at `https://<your-username>.github.io/<your-repo>/`.
2. Open a pull request here that adds one entry to [`docs/projects.js`](./docs/projects.js)
   (copy an existing entry, then fill in `title`, `authors`, `description`, `site`, and `repo`).
   If you don't want to open a PR, send your links to Djasahn.
